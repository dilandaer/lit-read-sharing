# 问题台账 · QUESTIONS

| Q-id | 问题（一句话） | 来源（key + 锚点） | 类型 | 我的初步想法 | 状态 |
|---|---|---|---|---|---|
| Q01 | | | 概念缺口 / 方法缺口 / 数据冲突 / 可推广 | | open |

**类型定义**

- **概念缺口**：某个物理量或机制在文献里没有自洽定义，导致不同文献说法无法比较。
- **方法缺口**：要回答某问题需要的方法目前不存在或代价不可接受（例如需要双激发又要
  O(N⁵)）。
- **数据冲突**：两篇文献对同一个量给出矛盾数值，且已排除口径差异。
- **可推广**：某个结论只在窄区间成立，推广出去会怎样是未知的。

**状态**：`open` → `answered`（给出答案并注明依据） / `dropped`（写清为什么放弃，通常是
发现口径不同而非真问题）
